title: Multimodal and vision
---

To a model, an image is a grid of numbers. Each pixel holds its brightness, or three values for red, green, and blue, usually from 0 to 255. A 1000 × 1000 color photo is 3 million numbers, and image models learn which patterns in those numbers make a cat, a table, or a letter.

**Convolutional neural network (CNN)** — a neural network (G2.4) built for grid data such as images, from two kinds of layers:

- **Convolution** — a small grid of learned weights, the **filter**, slides across the image; at each position it multiplies the pixels under it by its weights and adds the results into one number. The numbers from all positions form a **feature map**, which is high wherever the image contains the filter's pattern. One filter uses the same weights at every position, so a pattern it learns, such as an edge, is found anywhere in the image, with far fewer weights than a layer that connects every pixel to every neuron. A layer holds many filters, each learning its own pattern.
- **Pooling** — shrinking a feature map by summarizing each small region in one number, usually its maximum (**max pooling**). A 2 × 2 max pool with a step of 2 halves the width and the height, dropping 75% of the values while keeping the strongest responses. Later layers then cover more of the image at a lower cost.

A CNN stacks convolution and pooling layers, and each layer's filters run over the previous layer's feature maps. Visualizations of trained CNNs show early layers responding to edges and colors, and deeper layers to textures, object parts, and whole objects. The last layers turn the final feature maps into the output, such as a probability for each class.

**Vision transformer (ViT)** — a transformer (G3.1) applied to images by treating square pieces of the image as tokens. The image is cut into fixed-size **patches**, 16 × 16 pixels in the original paper; each patch is flattened into one vector, mapped to an embedding, and given a position. The patch sequence then goes through a standard transformer encoder, exactly like a sentence of tokens. A 224 × 224 image makes 14 × 14 = 196 patch tokens.

The difference from a CNN: a filter sees only a small neighborhood, so distant parts of an image meet only in deep layers, while attention relates any patch to any other from the first layer. ViT reached results on par with the best CNNs, provided it was first pretrained on a large image dataset: trained on many general images before training on the target task, so it starts from patterns already learned.

**OCR** (optical character recognition) — turning the text in an image, such as a scan, a photo, or an image-only PDF page, into machine-readable characters. It is often the first step of document ingestion: a RAG system (G1.7) can only search text it has. Two examples:

- **Tesseract** — an open-source OCR engine whose line recognizer is an LSTM (long short-term memory), a neural network that reads a line of text in sequence, left to right, covering over 100 languages.
- **Amazon Textract** — AWS's managed service. Beyond typed and handwritten text, it extracts **forms** (key-value pairs such as "Name: Ana") and **tables** with their cells, so the structure of a document survives.

**Multimodal LLM** — an LLM that takes more than text as input, such as images, in the same prompt as the text. One widely used design, that of the open research model LLaVA for example, connects a **vision encoder**, often a ViT, to the language model: the encoder turns the image into a sequence of vectors, which the LLM reads alongside the text tokens. A multimodal LLM can describe a photo, read a chart, or answer questions about a scanned invoice.

Images cost tokens like text does. Claude splits an image into 28 × 28-pixel patches and counts each patch as one visual token, so a 1000 × 1000 image costs ⌈1000 / 28⌉ × ⌈1000 / 28⌉ = 36 × 36 = 1,296 tokens; larger images are scaled down first. Vision LLMs can hallucinate (G3.2) as well: Anthropic warns that Claude may misread low-quality, rotated, or very small images and gives only approximate counts of many small objects.
